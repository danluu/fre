or performance claim. Closing a row requires code plus the named evidence; a
fallback or explicit rejection keeps the engine correct but does not close the
compatibility gap.

## Status rules

- **active** means the release claim is blocked.
- **mitigated, open** means current code fails explicitly instead of returning a
  wrong result, but required compatibility remains missing.
- **closed** requires a link to deterministic tests or qualification artifacts;
  prose analysis is insufficient.

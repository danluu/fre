# Search tag-29 static-link proof

This result-blind verifier closes the construction chain for the complete
frozen tag-29 topology inventory. It does not read timing results, Rebar, or
network data and cannot authorize promotion by itself.

The controller stages one flat, immutable artifact directory containing
`build-receipt.json`, `link-invocation-receipt.json`, `linked-image`,
`linked-image.map`, 808 implementation objects, 808 glue objects, 808
successful compile receipts, and 114 structural-refusal receipts. The verifier
opens every member through one held directory descriptor without following a
symlink.

For every eligible literal it proves this injective chain:

`semantic literal -> compile receipt -> implementation/glue bytes -> exact
identity-suffixed symbols -> one expanded linker input each -> exact link-map
providers -> retained final-image definitions`

Every ineligible literal must independently carry an authenticated compiler
refusal. Missing objects, unused objects, duplicate symbols, aggregate
substitution, or a fast-only subset fail the proof.

The invocation is:

```text
python3 verify_linked_candidates.py \
  contract-v1.json OBJECT_CANDIDATES LITERAL_DISPOSITIONS \
  ARTIFACT_DIRECTORY NEW_OUTPUT
```

The output is a canonical
`fre.aot.search-tag29-compiler-object-link-evidence.v1` envelope for the
separate pre-result campaign authority. It explicitly has no performance or
promotion authority.

# Search V22 persistent learned-wide candidate

V22 is a result-blind successor to V21. It was designed and preregistered
before any V21 performance timing began. It resolves V21's predeclared
current-group-only limitation by retaining the source-derived mismatch byte
and offset in Q24/Q25 and screening that learned column first across later
64-candidate groups.

`preregistration-v1.json` freezes the design, correctness prerequisites,
fixture construction, performance gate, and forbidden adaptations. Rebar is
not a design, routing, threshold, membership, or acceptance input.
